Tres réplicas de web, y lo que falta después

El archivo es el de la sesión: web se construye y declara ports: ["8080:5000"], db monta el volumen pgdata y cache solo existe dentro de la red. Pedir tres réplicas de web cuesta una bandera. Lo que viene después es contar qué queda arriba, ver con qué choca la orden y decidir qué hace falta para que esas réplicas sirvan tráfico.

3. El límite de Compose plano

Sin el puerto fijo la orden pasa, y docker compose ps muestra las tres réplicas en marcha.

¿Qué queda sin resolver con eso?

Correr varias copias y repartir el tráfico entre ellas son dos trabajos distintos. Compose hace el primero; el segundo se lo deja a NGINX o HAProxy delante, o se pasa a Swarm, donde el balanceo viene con el servicio.
