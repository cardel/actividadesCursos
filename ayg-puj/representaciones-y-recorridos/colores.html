Dos colores: el recorrido en profundidad que decide si un grafo es bipartito

Un recorrido en profundidad donde la marca de visitado lleva además un color. La actividad tiene tres tramos: unas preguntas para plantear el problema, la corrida del código sobre tres grafos, donde usted decide el color de cada nodo, y un grafo distinto para intentarlo sin ayuda. Una respuesta equivocada explica qué falló y se puede volver a intentar.

1. El planteamiento

Se tiene un grafo no dirigido. Se quiere pintar cada nodo con uno de dos colores de modo que ninguna arista una dos nodos del mismo color. Un grafo así se llama bipartito. Se pide decidir si un grafo dado lo es.

2. La corrida sobre tres grafos

Se abre al terminar las preguntas.

Borde negro: el nodo u de la llamada de arriba. Arista ámbar: la que se está mirando. Arista roja: un choque.

3. Qué responde el código con cada error

Se abre al terminar las preguntas.

Son errores que compilan y corren. Escoja uno y mire cómo queda el grafo.

4. Inténtelo sin ayuda

Se abre al terminar las preguntas.

Toque un nodo para cambiarle el color. Cuando termine, diga si su coloreo funciona o si este grafo no se puede pintar.
