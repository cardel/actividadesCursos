Tres formas de contestar lo mismo

Sumar un rango y cambiar una posición se pueden resolver recorriendo el arreglo, con un arreglo de prefijos o con el árbol de segmentos. Las tres contestan igual y cuestan distinto. Aquí se reparte la faena y la página cuenta casillas.

1. Las tres

recorrer el arreglo

def consulta_recorrido(A, ql, qr):
    suma = 0
    for i in range(ql, qr + 1):
        suma = suma + A[i]
    return suma


def cambio_recorrido(A, i, valor):
    A[i] = valor

La consulta lee una casilla por posición del rango. El cambio escribe una.

arreglo de prefijos

def armar_prefijos(A):
    P = [0] * (len(A) + 1)
    for i in range(len(A)):
        P[i + 1] = P[i] + A[i]
    return P


def consulta_prefijos(P, ql, qr):
    return P[qr + 1] - P[ql]


def cambio_prefijos(A, P, i, valor):
    A[i] = valor
    for k in range(i, len(A)):
        P[k + 1] = P[k] + A[k]

La consulta es una resta, dos lecturas. El cambio deja mal todas las sumas desde esa posición y hay que rehacerlas.

árbol de segmentos

S = build(A)              # escribe una casilla por vértice
query(S, ql, qr)          # visita los vértices que el rango abre
update(S, i, valor)       # reescribe la hoja y sus ancestros

Las dos cuentas del árbol no salen de una fórmula: la página recorre la recursión y cuenta los vértices, igual que en las otras dos actividades.
