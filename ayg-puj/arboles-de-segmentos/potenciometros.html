Potenciómetros

UVa 12086 pide exactamente las dos operaciones de la sesión sobre una fila de resistencias, y la única traducción que hay que hacer es la de los índices. Aquí corre una sesión de seis acciones: cada medida se predice antes de verla y cada cambio muestra la rama que reescribe.

1. El problema

Una fila de N resistencias, numeradas desde 1. Después llegan acciones, una por línea, hasta la palabra END:

  • S x r pone la resistencia x en r ohmios.
  • M x y mide la resistencia del tramo de x a y, que en serie es la suma, y la imprime.

UVa 12086, Potentiometers, https://vjudge.net/problem/UVA-12086. La página pide cuenta para ver el enunciado y para enviar.

Tres cosas del formato: el caso cierra con la palabra END y no con un número, la acción llega como palabra antes de sus dos enteros, y un N de 0 termina la entrada. La lectura en C++ queda así:

int n;
while (scanf("%d", &n) == 1 && n != 0) {
    for (int i = 0; i < n; i++) {
        int r;
        scanf("%d", &r);          // r va a la posicion i del arreglo
    }
    char accion[8];
    scanf("%s", accion);
    while (accion[0] != 'E') {
        int x, y;
        scanf("%d %d", &x, &y);
        if (accion[0] == 'S') {
            // poner la resistencia x en y
        } else {
            // medir de x a y
        }
        scanf("%s", accion);
    }
}
