El valor más frecuente de un rango

La consulta ya no pide una suma: pide cuántas veces aparece el valor que más se repite. Como la secuencia llega ordenada, los valores iguales forman tramos seguidos, y el árbol se levanta sobre los largos de esos tramos. Aquí corre la compresión del archivo de la sesión, línea por línea, y después las cuatro consultas, cada una predicha antes de verla. El número que acompaña a cada línea es el de su archivo.

1. El problema

Llega una secuencia de N enteros en orden no decreciente y después Q consultas. Cada consulta trae dos posiciones i y j, numeradas desde 1, y pide cuántas veces aparece el valor más frecuente entre ellas.

UVa 11235, Frequent values, https://vjudge.net/problem/UVA-11235. La página pide cuenta para ver el enunciado y para enviar.

Contar a mano el rango cuesta O(N) por consulta. Con N y Q de cien mil, eso no alcanza.

Tres cosas del formato: un N de 0 termina la entrada, los valores pueden ser negativos y las dos posiciones de cada consulta llegan desde 1. La lectura en C++ queda así:

int n, q;
while (scanf("%d", &n) == 1 && n != 0) {
    scanf("%d", &q);
    for (int k = 0; k < n; k++) {
        int x;
        scanf("%d", &x);           // x va a la posicion k del arreglo
    }
    for (int k = 0; k < q; k++) {
        int i, j;
        scanf("%d %d", &i, &j);    // las posiciones llegan desde 1
    }
}
