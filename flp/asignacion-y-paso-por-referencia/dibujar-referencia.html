Dibujar la cadena con paso por referencia

Cuatro programas sobre el intérprete 2 PasoPorReferencia (EOPL §4.5.1). En cada uno se pide la cadena en el instante en que empieza a evaluarse una expresión del cuerpo de un procedimiento. Cada ligadura guarda una referencia, y un parámetro cuyo operando fue una variable guarda la misma referencia de esa variable, aunque el eslabón de la variable no esté en la cadena. Al pedir la cadena del intérprete aparece con el almacén debajo, y los alias se ven como flechas que llegan a la misma celda.

El lenguaje es el mismo de la asignación: las expresiones del lenguaje con letrec más begin e; e; … end y set id = e. El ambiente inicial liga x = 4, y = 2, z = 5 sobre a = 4, b = 5, c = 6, en las celdas 0 a 5. Un operando que es una variable entrega su propia referencia; cualquier otro recibe una celda nueva.
Un eslabón se escribe con sus ligaduras entre corchetes: [p=(a-ref 6), q=(a-ref 8)]. Una referencia también puede escribirse ref 6. Los dos eslabones del ambiente inicial y el vacío los pone la página.
