letrec con referencias

El marco de un letrec guarda nombres, parámetros y cuerpos, igual que en el lenguaje sin asignación. Lo que cambia está en apply-env: el ambiente tiene que devolver una referencia, así que buscar uno de esos nombres fabrica la clausura y además le reserva una celda (EOPL §4.3). Siete programas para contar celdas y clausuras; en dos de ellos una asignación se pierde sin que nada falle.

El lenguaje es el del intérprete 1 Asignacion: números, variables, true y false, las primitivas antes del paréntesis y con comas, if e then e else e, let id = e … in e, proc(id, …) cuerpo, letrec, la aplicación (rator rand …), begin e; e; … end y set id = e, que devuelve 1. Las celdas 0 a 5 son las del ambiente inicial, x = 4, y = 2, z = 5 sobre a = 4, b = 5, c = 6; «celdas que reserva el programa» cuenta las que vienen después. Si el valor es una clausura, basta con escribir clausura.
