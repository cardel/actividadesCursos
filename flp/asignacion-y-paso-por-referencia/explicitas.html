Referencias explícitas

En el lenguaje de EOPL §4.2 el programa maneja la memoria a mano: newref reserva una celda, deref la lee y setref la escribe, y una referencia es un valor como cualquier otro. Ocho programas para predecir el valor y alguna cuenta del almacén. Al comprobar se abre la traza, con una fila verde por cada celda que se reserva y una azul por cada escritura, y la cadena de ambientes con el almacén dibujado debajo: cada flecha va de una ligadura a la celda que nombra su referencia.

El lenguaje es el del intérprete 0 ReferenciasExplicitas: números, variables, true y false, las primitivas antes del paréntesis y con comas (+(e,e), -(e,e), *(e,e), add1(e), sub1(e), ==(e,e)), if e then e else e, let id = e … in e, proc(id, …) cuerpo, letrec, la aplicación (rator rand …), que va sin comas, begin e; e; … end, newref(e), deref(e) y setref(e, e), que devuelve 1. No hay set. El ambiente inicial liga x = 4, y = 2, z = 5 sobre a = 4, b = 5, c = 6, sin celdas: en este lenguaje el ambiente guarda valores. Cada programa empieza con el almacén vacío.
