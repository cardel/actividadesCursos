Reglas de generación de ecuaciones

Tipar un programa de INFERRED es escribir el sistema de ecuaciones que genera y resolverlo (EOPL §7.4). Aquí se escribe el sistema: cada bloque muestra un programa, nombra sus variables de tipo y pregunta qué ecuación aporta cada parte. Se empieza por un programa de una sola ecuación y se llega a uno de cinco. Los sistemas y los tipos de esta página se midieron con type-of-program.

Las variables de tipo se escriben t1, t2, … El interpretador las imprime como tvar1, tvar7 y las numera en el orden en que las fue pidiendo, así que el número de una misma variable cambia entre corridas y no hay que acertarlo. Lo que importa es cuál es cuál dentro del programa.
Dos reglas escriben las ecuaciones. La de la aplicación, que vale también para las primitivas, escribe una sola por aplicación, siempre de la forma tipo del operador = (tipos de los operandos -> variable fresca del resultado), y la variable fresca pasa a ser el tipo de la aplicación. La del if escribe dos: la prueba contra bool y las dos ramas una contra otra. Las ocho primitivas tienen tipo fijo: +, - y * son (int * int -> int); add1 y sub1, (int -> int); < y >, (int * int -> bool); y zero?, (int -> bool).

Resueltos

ProgramaEcuacionesTipo
proc (? x) add1(x)1(int -> int)
proc (? x) if x then 1 else 22(bool -> int)
proc (? f, ? x) (f x)1((t2 -> t3) * t2 -> t3)
proc (? p, ? n) if (p n) then add1(n) else 04((int -> bool) * int -> int)
proc (? f, ? x) if zero?(x) then (f x) else add1(x)5((int -> int) * int -> int)
El conjunto de ecuaciones es lo que determina el tipo; el orden en que se recogen, no. El interpretador tipa la prueba, después la rama del else y después la del then, y por eso una ecuación puede llegar con un lado ya resuelto por otra anterior.

Un ejercicio más

Escriba un programa de INFERRED que genere exactamente tres ecuaciones, que una de ellas relacione dos variables de tipo entre sí y que el tipo inferido deje por lo menos una variable sin resolver. Entregue el programa, el nombre que le da a cada variable de tipo, las tres ecuaciones y el tipo que resulta. Que no sea ninguno de los cinco de la tabla.
