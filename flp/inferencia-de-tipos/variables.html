Variables de tipo

Cada ? se convierte en una incógnita: una variable de tipo con su número y un contenedor que se llena a lo sumo una vez. Tres bloques: qué es el TAD, cuándo dos partes del programa llevan la misma variable y qué pasa cuando dos usos le piden tipos distintos. Los tipos de esta página se midieron con type-of-program.

El interpretador imprime cada variable con su número serial, tvar10 o tvar34, y ese número depende del orden en que se pidieron las variables: el contador no se reinicia entre programas, así que el mismo programa medido dos veces imprime números distintos. En esta página las variables libres se escriben t1, t2 y t3, y lo que se pregunta es cuáles posiciones comparten variable, no qué número le tocó a cada una.

Resueltos

ProgramaTipo
proc (? x) x(t1 -> t1)
proc (? x, ? y) x(t1 * t2 -> t1): nadie menciona a y
proc (? f, ? x) (f x)((t1 -> t2) * t1 -> t2)
proc (? f, ? x) (f (f x))((t1 -> t1) * t1 -> t1)
proc (? f) proc (? x) (f (f x))((t1 -> t1) -> (t1 -> t1))
proc (? f, ? g) proc (? x) (f (g x))((t2 -> t3) * (t1 -> t2) -> (t1 -> t3))
La ecuación de la aplicación es la que iguala dos posiciones: el parámetro del operador con el argumento que recibe. Aplicar un procedimiento a su propio resultado iguala su entrada con su salida.

Un ejercicio más

Escriba un programa cuyo tipo sea ((t1 * t2 -> t1) * t2 -> (t1 -> t1)) y otro cuyo tipo lleve exactamente tres variables libres distintas. Mida los dos con type-of-program y escriba, para cada uno, qué ecuación obliga a cada repetición de una variable. Después busque un programa de tres parámetros que el chequeo de ocurrencia rechace, y diga qué variable aparece dentro de su propio tipo.
