# Ejercicios · Estructuras de Datos · Árboles y árboles binarios

El vocabulario del árbol con raíz y el árbol binario con sus vacíos. Cada enlace abre una actividad que se trabaja directo en el navegador.

## [contener](./contener.html){ target=_blank rel=noopener }

Un organigrama guardado en una lista, dos organigramas que dan la misma lista y lo que cuesta preguntar qué contiene una dependencia.

## [terminologia](./terminologia.html){ target=_blank rel=noopener }

Padre, hermanos, grado, profundidad, altura y niveles en un árbol de once nodos, y el mismo árbol guardado con primer hijo y hermano siguiente.

## [vacios](./vacios.html){ target=_blank rel=noopener }

Un árbol de nueve nodos armado con crearNodo: cuántos vacíos tiene, cuántos hijos tiene cada nodo y qué cambia al cruzar izq y der.
