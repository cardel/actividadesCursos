# Ejercicios · Estructuras de Datos · Recorridos de un árbol binario

Preorden, inorden y posorden, recursivos y con pila explícita, y lo que se hace con ellos. Cada enlace abre una actividad que se trabaja directo en el navegador.

## [predecir](./predecir.html){ target=_blank rel=noopener }

Los tres recorridos de un árbol de nueve nodos, primero predichos y después numerados.

## [expresion](./expresion.html){ target=_blank rel=noopener }

El árbol de (9 − 4) * 2 − 12 / (1 + 3): las notaciones prefija y postfija, lo que devuelve cada operador y la postfija evaluada con una pila.

## [pila](./pila.html){ target=_blank rel=noopener }

preordenPila, inordenPila y posordenPila vuelta por vuelta sobre un árbol de siete nodos.

## [liberar](./liberar.html){ target=_blank rel=noopener }

El orden de los delete de liberar y tres versiones que borran un nodo antes de terminar con él.

## [reconstruir](./reconstruir.html){ target=_blank rel=noopener }

Un árbol de ocho nodos rehecho rango por rango, su posorden y por qué el preorden y el posorden no alcanzan.

## [columnas](./columnas.html){ target=_blank rel=noopener }

Un árbol que llega en preorden con −1 en cada vacío, leído número por número, y la suma de los datos de cada columna.
