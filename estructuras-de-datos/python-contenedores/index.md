# Ejercicios · Estructuras de Datos · Contenedores de Python

`list`, `deque`, `dict`, `set` y `heapq`: lo que guarda cada uno por dentro y
lo que cuesta cada operación. Cada enlace abre una actividad que se trabaja
directo en el navegador.

## [crecer](./crecer.html){ target=_blank rel=noopener }

Una lista que recibe m llamadas a `append`, línea por línea: cuántas veces
cambia de arreglo y cómo crece ese número con m.

## [list](./list.html){ target=_blank rel=noopener }

Diez `append` con el arreglo dibujado en cada paso, la capacidad después de
cuarenta, lo que se corre al insertar y al quitar, y lo que cuesta buscar
muchas veces.

## [deque](./deque.html){ target=_blank rel=noopener }

Una cola de impresión paso a paso, un programa que usa los dos extremos, mil
atenciones con `pop(0)` y cuándo conviene una `list`.

## [dict-set](./dict-set.html){ target=_blank rel=noopener }

El orden en que un `dict` recorre sus claves, las casillas donde un `set`
guarda enteros, el error de leer una clave que no está, qué puede ser clave y
lo que cuesta quitar repetidos.

## [heapq](./heapq.html){ target=_blank rel=noopener }

Seis `heappush` con el árbol y el arreglo, dos `heappop`, `heapify`, tuplas
con la misma prioridad, el mayor con las claves negadas y dónde está el segundo
menor.
