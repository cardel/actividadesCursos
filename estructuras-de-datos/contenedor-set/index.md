# Ejercicios · Estructuras de Datos · Contenedor set

El contenedor `set`: claves distintas y en orden, `count`, `find`, `erase`,
`lower_bound` y `upper_bound`, cuándo conviene frente a `map`, `unordered_map` o
un `vector` ordenado, y un problema de juez. Cada enlace abre una actividad que
se trabaja directo en el navegador.

## [operaciones](./operaciones.html){ target=_blank rel=noopener }

Los buses que pasan por un peaje: qué imprime un programa que cuenta repetidos
con `count`, avanza con `++it` desde `find` y borra con `erase`.

## [bordes](./bordes.html){ target=_blank rel=noopener }

Las salidas de un tren: `lower_bound` y `upper_bound`, la salida anterior a un
minuto, cuántas caen en un intervalo y la trampa del `lower_bound` de
`<algorithm>`.

## [elegir](./elegir.html){ target=_blank rel=noopener }

Cinco situaciones para escoger entre `set`, `map`, `unordered_map` y un `vector`
ordenado una sola vez, con lo que falla en cada alternativa.

## [compuestas](./compuestas.html){ target=_blank rel=noopener }

UVa 10391, Compound Words, con un `set<string>`: por qué una palabra de tres
partes no sale, qué estrategia se descarta por tiempo, qué imprime un
diccionario propio y cuántos cortes se prueban.
