# Ejercicios · Estructuras de Datos · Proceso de compilación

Las cuatro etapas que separan un archivo de texto de un ejecutable y las seis
fases del compilador, con los errores que nacen en cada una. Cada enlace abre
una actividad que se trabaja directo en el navegador.

## [etapas](./etapas.html){ target=_blank rel=noopener }

Las opciones `-E`, `-S` y `-c`, lo que agrega el preprocesador a
`Cuadrados.c`, lo que reporta `nm` sobre el objeto, el `printf` que se volvió
`puts` y una macro que arrastra un punto y coma.

## [fases](./fases.html){ target=_blank rel=noopener }

Qué entrega cada fase y en cuál se detienen un carácter suelto, un paréntesis
sin cerrar, un nombre repetido, un `break` sin ciclo y una función definida en
dos archivos.
